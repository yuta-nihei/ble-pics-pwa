🚦 PICS Viewer

高度化PICS のBLE信号（メーカーID 0x01CE）を受信して、歩行者信号をリアルタイム表示します。受信専用です。実際の横断は現地の信号を見て判断してください。

iPhone / Safariでは実機受信できません。
iOSのSafari・Chrome（どちらもWebKit）には Web Bluetooth が無く、ホーム画面に追加したPWAでもBLEスキャンはできません。
・画面確認だけなら下の「デモを試す」が使えます
・iPhoneで実機受信したい場合は、Web Bluetooth対応ブラウザ Bluefy でこのページを開くか、先に作ったネイティブ版（Swift）が必要です
・Android / Windows / Mac の Chrome では、実験フラグ有効化で実機受信できる場合があります
Bluefyで開いています。 このまま使えます。始める前に Bluefy の設定で 「Enable BLE Advertisements」をON にして、Bluefyを再起動してください。そのあと受信方式は「Bluefy（デバイスを選んで監視）」のまま「スキャン開始」を押してください。PICS機器は名前が出ないことがあるので、選択画面では信号機らしき機器／不明なデバイスを選んでください。
